# Anti-Detect Multi-Profile Browser

## 🎯 Overview

This repository contains my personal implementation of an anti-detect multi-profile browser. This project was created to address the need for managing multiple browser profiles, each with its own proxy settings and Chrome account, for enhanced privacy and organization. It demonstrates my skills in browser automation, proxy management, and profile isolation using Python.

## ✨ Key Features

-   **Multi-Profile Management**: Allows the creation and management of multiple browser profiles.
-   **Proxy Support**: Enables configuration of individual proxy settings for each profile.
-   **Chrome Account Integration**: Supports the use of separate Chrome accounts for each profile.
-   **Anti-Detection Techniques**: Implements techniques to minimize browser fingerprinting and enhance privacy.
-   **Personal Project**: Developed to meet my own needs, showcasing practical problem-solving and self-directed learning.

## ⚙️ Tech Stack

-   **Python**: Core language for building the browser automation logic.
-   **Selenium**: Web automation framework for controlling browser instances.
-   **[Other: Requests, Beautiful Soup, Proxy]**

## 🚀 Get Started

1.  **Clone the repository:**

    ```
    git clone https://github.com/YaroslavPiskachov/anti-detect-multiprofile-browser.git
    ```

2.  **Navigate to the project directory:**

    ```
    cd anti-detect-multiprofile-browser
    ```

3.  **Install the required dependencies:**

    ```
    pip install -r requirements.txt
    ```

4.  **Run the application:**

    ```
    python main.py
    ```
